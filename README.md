# Fleet Telemetry Data Platform

A portfolio data-engineering project on AWS. It ingests truck sensor data,
transforms it into a queryable data lake, and serves fleet-health insights to a
React dashboard.

> Dataset: Kaggle "APS Failure at Scania Trucks". `vehicle_id` and `event_date`
> are **synthetic**. They are generated by a script because the source has no
> timestamps or vehicle IDs.

## Layout

```
infra/    AWS CDK app (Python): S3 zones, IAM, budget, Glue job, Athena workgroup
glue/     Glue PySpark job scripts (uploaded to S3 on deploy)
scripts/  Local helpers (prepare_dataset.py adds the synthetic columns)
docs/     Per-phase notes: what was built, what I learned, how to verify
```
